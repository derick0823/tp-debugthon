# Backlog

每個任務一個資料夾。**任務的狀態就是它所在的資料夾。**

| 資料夾 | 意思 |
|---|---|
| `todo/` | 還沒做 |
| `waiting/` | 卡在外部，例如等主辦單位通知 |
| `done/` | 做完了 |

## 規則

1. 任務資料夾命名 `NNN-<主題>`。編號照建立順序遞增，不重複使用。主題用英文小寫 kebab。
2. 每個任務資料夾裡有一份 `README.md`，寫負責人、為什麼、步驟、完成條件、紀錄。任務的附件（截圖、表單草稿）也放在同一個資料夾。
3. 狀態改變時，把整個任務資料夾搬到另一個狀態資料夾。`README.md` 裡**不寫狀態**，避免和資料夾位置不一致。
4. 做完時，在「紀錄」補一行日期和結果，再搬到 `done/`。
5. 負責人寫「你」「Claude」或隊友名字。
