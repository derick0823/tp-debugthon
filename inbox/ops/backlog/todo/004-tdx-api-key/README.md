## 申請連結

- 註冊頁：https://tdx.transportdata.tw/register
- 一般會員表單：https://tdx.transportdata.tw/register/general
- 拿金鑰的頁面（審核通過後）：https://tdx.transportdata.tw/user/dataservice/key

## 選哪一種會員

註冊頁有 3 種會員。**依你的 Email 網域決定**，不是自己選：

| 會員類型 | 適用對象（官方原文） | Email 網域 |
|---|---|---|
| 學研單位 | 公私立大專院校所屬教職人員、學生；公立學研機構所屬研究人員 | edu 或 org |
| 公部門會員 | 中央政府機關、交通部及部屬機關、地方政府機關 | gov |
| 一般會員 | 個人身份、私人企業、非公務機關之法人團體 | edu、org、gov 以外 |

用個人 Gmail 申請，就選「一般會員」。

⚠ 如果你想用工作信箱（例如 iii.org.tw），網域是 org，會被歸到「學研單位」。這要你自己判斷用哪個信箱比較合適。

## 申請之後

1. 等 TDX 審核。官方沒有寫要等多久，通過會寄信通知。
2. 審核通過後登入，到「會員中心 → 資料服務 → API 金鑰」（上面第三個連結）。
3. 按綠色「編輯」按鈕，就看得到 **Client Id** 和 **Client Secret**。每個帳號最多 3 組金鑰。
4. 把兩個值存到 `C:\Users\abrahamdong\.config\tdx\.env`，格式如下：

   ```text
   TDX_CLIENT_ID=...
   TDX_CLIENT_SECRET=...
   ```

5. **不要把金鑰貼進對話、repo、Discord 或任何共用文件。** Claude 會從那個檔案讀。

## 參考

- 不帶金鑰也能呼叫部分基礎服務，但每個來源 IP 每天上限 50 次【文件，第三方教學文章，可能過時】。
- 拿到金鑰後，要先用它換 Access Token 才能呼叫 API。Token 有效期 1 天【文件，第三方教學文章】。
- TDX 客服：tdx@motc.gov.tw，(02)2349-2803，週一到週五 9:00～12:00、13:30～18:00。
