# 012 查主計總處 2020 年人口及住宅普查的各區住宅屋齡

- 負責：未指派（候選：現況研究 c8，它做完 R1 後閒置中）
- 急不急：中。10/20 前做完，才來得及進方案。
- 為什麼：R1 發現官方說的「50 年以上老屋」用開放資料算不出來（H7），因為官方表只分「未滿 30 年／30 年以上」。GEM 全球曝險模型的臺灣住宅資料來自 2020 年普查，普查有「建造期間、構造材料、樓層數」【文件，GEM README】。如果普查公開了各區的建造期間分布，就能算出各區 50 年以上住宅的比例。

## 步驟

1. 找主計總處 2020 年人口及住宅普查的公開統計表（入口：https://eng.stat.gov.tw/cl.aspx?n=2398 ，中文版在主計總處網站）。
2. 確認有沒有「臺北市各區 × 建造期間」「× 構造材料」「× 樓層數」的表。記下建造期間的級距（例如民國 59 年以前、60～69 年……）。
3. 有的話，用 `pipelines/fetch/` 抓、`pipelines/stage/` 清洗，並在 `docs/extra-data.md` 補一節（請整合者改）。
4. 和 R1 的實價登錄推估、稅捐處房屋概況比對：三個來源各區的老屋比例差多少。

## 完成條件

- 知道普查有沒有區層級的建造期間表。有的話，已清洗並和 R1 結果比對。
