# #3 鼠患四處跑，衛生安全怎麼辦

- 官方標籤：衛生、GIS、風險模型
- 來源：https://puma.taipei/hackathon#issues （2026-10-17 抓取）

## 官方原文

> 傳統市場、夜市與餐飲聚落周邊的鼠患長年困擾市民，現行做法多停留在投藥與被動稽查。我們要如何整合餐飲登記密度、下水道管網分布、清潔隊清運排程與歷史通報，畫出「鼠患風險傳播地圖」，讓源頭治理精準到位？

> 沈伯洋說：老鼠要有食物和管道才能持續，錯過繁殖期就要等下一次才能處理。要做好垃圾與廚餘焚燒前的密封管理、確認垃圾車是否足夠、翻修管道與地下水道，並在繁殖期投放藥物，把前端預防做好。

（新聞連結：https://www.cna.com.tw/news/aloc/202605010231.aspx ，catalog slug `news-rats`）

注意事項：

1. **官方寫「含病媒通報」，但對不上。** 3,731,449 筆陳情資料中，沒有任何主類別或次類別名稱含「病媒」「鼠」「蟲」「蚊」。病媒通報可能被歸在別的類別，這點尚未查證。
2. **官方寫「食品業者登錄數（分區）」，但只有全市 1 列。**
3. 污水管線沒有座標。雨水人孔有座標，但兩者是不同系統（污水、雨水）。這份污水管線能不能用人孔編號對到位置，尚未查證。
4. 衛生局夜市專區：官方頁列的舊網址 SSL 憑證和網域不符。隊員回報新網址 https://foodtracer.health.gov.taipei/?aspxerrorpath=/Front/Nightmarket 。2026-10-17 從本機連新網址，第一次回 200（只有 668 bytes），之後伺服器直接斷線，Chrome 也顯示錯誤頁【實測】。網址裡的 `aspxerrorpath` 表示舊路徑在新網站上找不到，被導到錯誤處理頁【推論】。
5. 見鼠地圖：隊員 2026-10-17 從網頁匯出 CSV，存在 `data/raw/sanitation/ratdar-reports/manual-export-20261017T135057.csv`【實測】。
   - 1,433 筆，**是全台資料**。臺北市 949 筆、新北市 371 筆，其餘縣市都在 40 筆以下。
   - 時間範圍 2026-05-01 到 2026-10-17。
   - 欄位：通報時間、類型（鼠蹤、毒餌）、地點（縣市＋區或里）、狀態（已審核、待審核、已通報1999）、說明、照片網址、緯度、經度。
   - 臺北市各區：大安 146、信義 125、中山 110、松山 96、萬華 86、中正 85、士林 60、文山 59、大同 54、內湖 49、北投 47、南港 32。
   - **使用注意**【推論】：經緯度很精確，「說明」常描述住家（例如「由家中冷氣孔進入室內」），照片也可能拍到住家。規則禁止使用真實個資。Demo 時建議彙總到里或區，不直接秀出逐筆的說明、照片和精確點位。
