## 第 1 部分：官方原文

### 活動說明

> 「市長，你給我聽好了」收到了上千則市民的抱怨與建議。我們把它整理成 7 個市政痛點，邀請工程師、設計師、資訊人用一天時間，做出最小可行性方案（MVP），並做為未來市政推動的方針。

> 主辦：沈伯洋競選辦公室　統籌：資訊顧問 黑貘

> 「市長，你給我聽好了」資料（已去識別化）即將於此釋出。

> // 可以用模擬的資料

### 黑客松規則

> 報名即表示同意以下規則。違反行為準則者，主辦單位得請其離場並取消作品資格。

**報名**

> - 報名已提前於 10/14（三）14:00 截止，名額 80 人。入選後將公布名單與 email 通知，沒入選則不另行通知。
> - 可以單人組隊，每隊至少一名隊員，重複報名者將取消參與資格。
> - Day 1 在 Discord 提案，不另外媒合隊友，志同道合的隊伍可自行整合。
> - Day 2 現場依議題分桌或分區。同組至少一人到場，其他成員可遠端協作。
> - 報名資料只用於本活動聯繫。

> 先填隊伍名稱，再一次加入一位以上隊員；每位隊員各占一個名額。

**資料使用**

> - 可以用模擬的資料，不必真的串接 API。
> - README 須註明哪些是真實開放資料、哪些是模擬資料，Demo 時口頭說明。
> - 「市長，你給我聽好了」資料已去識別化，不得嘗試反推陳情人身分，也不得使用真實個資。「市長，你給我聽好了」資料僅限於此黑客松活動使用。
> - 開放資料依各資料集授權使用，多數為政府資料開放授權條款。

**作品規範**

> - 形式不限：App、網站、儀表板、系統原型、聊天機器人皆可，以可快速驗證的 MVP 為目標。
> - Demo 時現場操作，只有簡報或設計稿不算。
> - Day 1 起可開始討論與寫程式；可用開源套件與 AI 工具，須於 README 註明。
> - 建議在 README 寫「如果市府上任 100 天內要落地，需要做什麼」：哪個局處、哪些資料、多少成本。
> - 10/24 16:00 前透過主辦單位提供的隊伍專屬連結送出，填寫作品名稱與作品網址，可另附 GitHub 或 GitLab 程式碼網址；成員依報名資料。

**Demo 與票選**

> - 不設評審、不排名次，以線上票選選出前三名。
> - 現場 Demo 開放 10 組（視情況增至 15 組），10/24 16:30–17:00 直播，每組約 2 分鐘，現場填單抽順序。
> - 票選 10/24 16:30 開放，10/31（六）18:00 截止，在本頁投票。
> - 投票須以 Google 或 LINE 登入本站，每個帳號限投一次，最多選 3 件作品；灌票或自動化投票不予計入，同票並列。
> - 前三名經團隊同意，於票選截止後 7 日內刊登於沈伯洋競選官網。無獎金。

**著作權與開源**

> - 著作權歸團隊所有。
> - 經團隊同意，作品以開源授權（建議 MIT 或 CC BY 4.0）收錄於ㄅ級分持續迭代；不同意不影響參加與票選。

**行為準則**

> - 互相尊重，不分背景、性別、年齡與政治立場，禁止騷擾、歧視與人身攻擊。
> - 不得對市府或任何第三方系統做未經授權的掃描、壓測或入侵測試。
> - 16:30 起直播，現場會拍照錄影。不想入鏡請在報到時領取識別貼紙。
> - 本活動由沈伯洋競選辦公室主辦。參加黑客松不等於加入後援會；後援會於座談後開放自由報名。

## 第 2 部分：踩線檢查表（我們的解讀）

這一節不是官方原文。每一條後面標出對應的官方規則。

### 交件前一定要做到

1. **README 標出真實與模擬資料。** 每一份資料都要標。Demo 時也要口頭講。（資料使用）
2. **README 標出用了哪些開源套件與 AI 工具。** 包含 Claude 這類 AI 工具。（作品規範）
3. **Demo 必須現場操作。** 只有簡報或設計稿不算。（作品規範）
4. **16:00 前用隊伍專屬連結送出。** 要填作品名稱與作品網址。作品網址要能公開打開。（作品規範）
5. **Day 2 至少一位隊員到場。**（報名）

### 一定不能做

1. **不得使用真實個資。** 模擬資料也不能用真人姓名、電話、地址。（題目總則、資料使用）
2. **不得反推陳情人身分。** 「市長，你給我聽好了」資料也不能帶出活動外使用。（資料使用）
3. **不得對市府或第三方系統做未經授權的掃描、壓測或入侵測試。** 抓開放資料要正常下載，不要高頻輪詢即時 API。（行為準則）
4. **不得灌票或用程式自動投票。**（Demo 與票選）
5. **不得重複報名。**（報名）

### 建議做（加分，不是必要）

1. README 寫「市府上任 100 天內要落地，需要做什麼」：哪個局處、哪些資料、多少成本。（作品規範）
2. 決定要不要同意以開源授權收錄於ㄅ級分。不同意不影響參加。（著作權與開源）

### 還不知道、要等主辦通知

- Day 2 確切地點與入場方式（email 通知）。
- Discord 連結（email 通知）。
- 隊伍專屬提交連結（主辦提供）。
- 「市長，你給我聽好了」資料的釋出時間與格式（官方頁寫「即將於此釋出」）。
- **賽前準備的界線。**規則寫「Day 1 起可開始討論與寫程式」。我們的解讀：賽前只做資料層、設計稿、內部原型；產品程式與公開網址在 Day 1（10/23）之後完成。這個解讀要在 Day 1 的 Discord 向主辦確認【待確認，協調者決策草案 2026-10-18 第 1 節 E】。
