# C4：逐棟屋齡與構造的替代資料與推估技術

## 背景

我們是一支 3 人的黑客松隊伍，參加 2026-10-24 的臺北「市政 debug松」。題目要我們建立臺北市的「危老耐震風險加權評級模型」。最關鍵的兩個因子是**屋齡**與**建築結構**，但官方說「逐棟屋齡、結構類型未開放」。

我們手上已經有的替代資料：

- 臺北市各區「30 年以上／未滿 30 年」棟數（稅捐處房屋概況），只到區。
- 2001 年以後核發的建造與使用執照摘要、建築執照套繪圖（逐棟，但沒有老屋）。
- 內政部實價登錄：每筆交易有建築完成年月、主要建材、門牌（只有交易過的建物）。
- 臺北市門牌座標（115 萬筆）。
- 海砂屋清冊、地震列管建物（少量已知案例）。

## 你的任務

找出還有哪些資料或技術，可以推估臺北市**逐棟或細網格**的屋齡、樓層、構造。回答：

1. **開放的建物圖資**：OpenStreetMap 在臺北的建物覆蓋率，以及有多少建物有 `start_date`、`building:levels`、`building:material` 標籤（請實際用 Overpass API 或其他方式查一個小範圍抽樣，寫下查詢方法與時間）。Microsoft Building Footprints、Google Open Buildings（含 2.5D 高度）、Overture Maps 在臺灣有沒有資料。國土測繪中心的 3D 建物模型與建物輪廓能不能取得、授權條件。
2. **歷史影像**：臺灣有沒有開放的歷史航照或舊地形圖（例如中研院 GIS 中心的臺灣百年歷史地圖、農林航空測量所航照），可以用來判斷「某塊地在某年以前就有建物」。取得方式、授權、解析度。
3. **用 AI 推估屋齡或脆弱度的研究**：用街景影像、衛星影像、建物輪廓推估建造年代或耐震脆弱度的論文與開源模型。準確率多少、在亞洲城市有沒有驗證過、需要多少標註資料。
4. **統計推估方法**：用區域統計（例如區的屋齡分布）配合逐筆樣本（例如實價登錄）推估小區域分布的方法，例如小區域估計（small area estimation）、dasymetric mapping、迭代比例配適（IPF）。哪個最適合一天的黑客松。
5. **其他可能的資料源**：房屋稅籍資料（臺北市有沒有任何形式的公開）、自來水或電力接戶年份、門牌編釘年份、地政的建物第一次登記日期。

## 輸出

- 用繁體中文（台灣用語）寫一份 Markdown 報告。
- 最前面寫 10 行以內的摘要。
- 一張總表：「資料或方法 × 能推估什麼（屋齡、樓層、構造）× 空間尺度 × 取得難度 × 授權 × 一天內做得完嗎」。
- 每個主張標註證據等級：【實測】（你自己查過，附查詢方法與時間）、【文件】（附來源網址）、【推論】、【待確認】。
- 最後一節「建議」：在一天的黑客松裡，最務實的屋齡推估做法是什麼，以及要怎麼在 README 裡誠實說明它是推估值。
