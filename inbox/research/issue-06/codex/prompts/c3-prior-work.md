# C3：臺灣既有的同類專案、報導與作品

## 背景

我們是一支 3 人的黑客松隊伍，參加 2026-10-24 的臺北「市政 debug松」。題目是「危老耐震如何查，風險評級怎麼找」：整合屋齡、建築結構、高齡人口、土壤液化潛勢、狹小巷弄消防搶救困難，建立風險加權評級模型，讓市府排出老屋健檢與公辦都更的優先順序。

作品要在一天內做出 MVP，並由線上票選。我們不想重做別人已經做過的東西。我們要知道臺灣已經有哪些類似的工具、地圖、報導、黑客松作品，才能找出差異化。

## 你的任務

找出臺灣已經存在的相關作品，分 5 類：

1. **政府工具**：例如臺北市城市儀表板、土壤液化潛勢查詢系統（soil.taipei，2026-10-31 關站）、經濟部地礦中心全國版液化查詢、內政部或臺北市的危老、都更、海砂屋查詢網站、國土測繪中心 3D 建物、防災地圖。
2. **公民科技**：g0v 相關專案、開源地圖、老屋或危老相關的民間網站與 GitHub repo。
3. **數據新聞**：報導者、天下、鏡週刊、公視新聞實驗室、中央社等媒體做過的老屋、危老、耐震、液化、雙老互動報導。
4. **黑客松與競賽作品**：總統盃黑客松、臺北市或其他縣市的資料競賽、學生專題裡做過的老屋耐震或防災作品。
5. **商業產品**：房仲或新創提供的屋齡、耐震、液化查詢功能。

每個作品寫：名稱、網址、誰做的、年份、功能、用了哪些資料、目前還在不在線、優點、缺點或缺口。

## 輸出

- 用繁體中文（台灣用語）寫一份 Markdown 報告。
- 最前面寫 10 行以內的摘要。
- 一張總表：「作品 × 功能（查詢、地圖、排序模型、給市府、給民眾、即時更新）」。
- 每個主張標註證據等級：【文件】（附來源網址與查詢日期）、【推論】、【待確認】。網址要親自確認能不能打開，打不開就標【待確認】並註明。
- 最後一節「還沒有人做過的缺口」：條列我們可以差異化的方向。
