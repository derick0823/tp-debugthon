# 義大利：耐震稅賦抵減（Sismabonus）與建物耐震風險分級（A+～G）

- 檔名代號：it-sismabonus-seismic-classification
- 查核日：2026-10-17
- 對應痛點：
  - P3：義大利把耐震風險做成 A+～G 八級，像家電能源標章。屋主看得懂「我家是 E，補強後變 C」，補助也跟著級數跳。這是臺北「屋主不知道自家風險」最直接的對照。
  - P2：稅賦抵減只有「有稅可抵、有錢先付」的人用得到。官方預算機關證實抵減高度累退、集中在北部。市場與財力決定誰補強，不是風險。
  - P5：分級有「傳統法」與「簡化法」兩種，結果可能不同。義大利用「星號」標示簡化法結果，是處理「推估 vs 鑑定」版本差異的現成做法。
- 解法類別：財務、技術（分級方法）、法規
- 制度起始年：2013（耐震抵減首度入法）；2017（Sismabonus 擴大＋DM 58/2017 分級）；最近一次重大變動：2023～2026（停止抵減權移轉、比率降到 36%～50%、2027 起條文併入新所得稅法典）

## 一句話

八級耐震標示可以直接借；但「抵稅換補強」花了上千億歐元，錢流向有錢的北部。

## 背景痛點

- 義大利基礎建設與運輸部（Ministero delle Infrastrutture e dei Trasporti，MIT）2017 年的說法：過去 50 年地震造成約 5,000 人死亡，政府平均每年約 30 億歐元花在緊急應變與重建。【文件】[3]
- MIT 認為原因除了地震頻繁，主要是「既有建物的高脆弱性」。【文件】[3]
- 2017 年以前，耐震補強抵減只限高危險的第 1、2 震區，且不論補強效果都同一比率。【文件】[3]
- 2017 年改制目標：讓「全國民間建物的自願性評估與預防」大規模發生，不設排序、不用排隊。【文件】[3]

## 做法

兩件事綁在一起：

1. **分級**：基礎建設與運輸部部令 DM 58/2017（2017-02-28，2017-03-01 生效；DM 65/2017、DM 24/2020 修正）附件 A《建物耐震風險分級指引》（Linee guida per la classificazione del rischio sismico delle costruzioni），把建物分成 A+～G 八級。【文件】[2][3]
2. **抵減**：屋主請建築師或工程師評定「補強前」與「補強後」的級數。級數進步越多，抵減比率越高。抵減分 5 年從所得稅扣。【文件】[1][3]

2020～2025 年另有 Superbonus（110% 超級抵減）。它把耐震與節能的抵減拉到 110%，並允許把抵減權賣給建商或銀行。【文件】[4][6]

## 機制細節

### A. 分級怎麼算（傳統法，metodo convenzionale）

適用所有建物類型。用現行《建築技術規範》（NTC）的一般分析方法。【文件】[2]

**兩個參數，取較差者。**【文件】[2][3]

1. **PAM（Perdita Annua Media attesa，年平均預期損失）**：建物一生中地震造成的修復成本，平均到每年，以「重建成本」的百分比表示。這是經濟面。
2. **IS-V（Indice di Sicurezza per la Vita，生命安全指標）**：建物達到「生命安全極限狀態」（SLV）的地表加速度（PGA_C，容量）÷ 當地新建物設計要求的 PGA（PGA_D，需求）。這是安全面。

**PAM 的計算步驟**（附件 A 第 2.1 節，原文 11 步）【文件】[2]

1. 結構分析，求出達到 4 個極限狀態的容量地表加速度 PGA_C：SLO（可運轉）、SLD（損害限制）、SLV（生命安全）、SLC（接近崩塌）。可簡化只算 SLV 與 SLD。
2. 把每個 PGA_C 換成回歸期 T_rC。沒有更細的資料時用：
   - `T_rC = T_rD × (PGA_C / PGA_D)^η`，`η = 1/0.41`（全國平均）。
   - 依岩盤加速度 a_g 分 4 段，η 可改用 1/0.49、1/0.43、1/0.356、1/0.34。
3. 每個極限狀態的年超越頻率 `λ = 1 / T_rC`。SLO、SLD 的 λ 取「自己算出的值」與「SLV 的值」中較大者（不能先達生命安全才達損害）。
4. 加兩個約定點：
   - SLID（損害起始）：λ = 0.1（回歸期 10 年），損失 0%。
   - SLR（需重建）：λ 等於 SLC 的 λ，損失 100%。
5. 每個極限狀態對應「重建成本百分比」CR（附件 A 表 3）：

| 極限狀態 | CR |
|---|---|
| SLR（需重建） | 100% |
| SLC（接近崩塌） | 80% |
| SLV（生命安全） | 50% |
| SLD（損害限制） | 15% |
| SLO（可運轉） | 7% |
| SLID（損害起始） | 0% |

6. PAM ＝ 以 (λ, CR) 為點畫折線，折線下的面積，再加上 (λ=0, CR=100%) 這一點：
   - `PAM = Σ_{i=2..5} |λ(SL_i) − λ(SL_{i−1})| × [CR(SL_i) + CR(SL_{i−1})] / 2 + λ(SLC) × CR(SLR)`
   - i=1 是 SLID，i=5 是 SLC。
7. 只算兩個極限狀態時，其他兩個用近似：`λ_SLO = 1.67 × λ_SLD`，`λ_SLC = 0.49 × λ_SLV`。

**PAM 分級（附件 A 表 1）**【文件】[2]

| PAM | PAM 等級 |
|---|---|
| PAM ≤ 0.50% | A+ |
| 0.50% < PAM ≤ 1.0% | A |
| 1.0% < PAM ≤ 1.5% | B |
| 1.5% < PAM ≤ 2.5% | C |
| 2.5% < PAM ≤ 3.5% | D |
| 3.5% < PAM ≤ 4.5% | E |
| 4.5% < PAM ≤ 7.5% | F |
| 7.5% ≤ PAM | G |

- 參考點：設計年限 50 年、剛好符合現行規範的新建物，PAM = 1.13%，屬 B 級。設計年限 75 年為 0.87%、100 年為 0.74%，在 A 級邊緣。【文件】[2]

**IS-V 分級（附件 A 表 2）**【文件】[2]

| IS-V | IS-V 等級 |
|---|---|
| 100% < IS-V | A+ |
| 80% ≤ IS-V < 100% | A |
| 60% ≤ IS-V < 80% | B |
| 45% ≤ IS-V < 60% | C |

- IS-V 只有 7 級（沒有 G）。剛好符合新建規範的建物 IS-V 屬 A 級。【文件】[2]
- **最終風險等級 ＝ PAM 等級與 IS-V 等級中較差的一個。**【文件】[2]

### B. 分級怎麼算（簡化法，metodo semplificato）

只適用**磚石造**（muratura）。不用計算，靠現場判斷。【文件】[2]

1. 依歐洲巨觀震度表 EMS-98 的 7 種磚石構造類型，找出建物的「平均脆弱度等級」V1～V6（V6 最脆弱）。
2. 若有嚴重劣化、施工品質差、可能局部崩塌的特徵，可往更脆弱調整（只能往差的方向調）。
3. 依所在震區（1～4 區，1 區最危險）對應風險等級（附件 A 表 5）：

| 風險等級 | 1 區 | 2 區 | 3 區 | 4 區 |
|---|---|---|---|---|
| `A+*` | | | | V1～V2 |
| `A*` | | | V1～V2 | V3～V4 |
| `B*` | V1 | V1～V2 | V3 | V5 |
| `C*` | V2 | V3 | V4 | V6 |
| `D*` | V3 | V4 | V5～V6 | |
| `E*` | V4 | V5 | | |
| `F*` | V5 | V6 | | |
| `G*` | V6 | | | |

- **簡化法的等級一律加星號（`A+*`、`A*`、`B*`…）**，和傳統法區分。【文件】[2]
- 簡化法只能用於「局部補強」，**最多進步 1 級**。附件 A 表 6 逐一列出每種磚石造要做哪些補強（修復劣化區、消除水平推力、牆體面外穩定、牆與樓板連結），才算進步一級。【文件】[2]
- 補強前後必須用同一種方法評定。【文件】[2]
- 附件 A 自己承認：簡化法是「可信但不一定和傳統法一致的估計」。【文件】[2]

### C. 怎麼交到屋主手上

- 流程（MIT 2017）：【文件】[3]
  1. 屋主委託建築師或工程師。
  2. 專業者評定「現況等級」。
  3. 設計補強，評定「補強後等級」。
  4. 專業者簽署「宣誓聲明」（asseverazione，附件 B 格式），證明兩個等級與補強效果。
  5. 完工後由工地主任與結構驗收人確認依設計施作。
- DM 58/2017 在公共工程高等委員會（CSLP）設「常設監測委員會」，評估全國耐震預防的成效。【文件】[3]

## 批評與失敗

- **成本失控**（國會預算辦公室 UPB，2024-04-19）：【文件】[5]
  - Superbonus 實際支出「遠超預期，前所未見」。
  - UPB 列的原因：
    - 抵減比率超過 100%，屋主不再在意價格。
    - 上限比其他抵減高。
    - 把原本低比率的工程「拖進」高比率。
    - 抵減權可以賣給建商或銀行，無收入者也能做。
    - 自動適用，沒有事前核准，無法設總額上限。
  - 後續因素：
    - 多次延長到 2025 年。
    - 「要縮減」的消息造成搶件。
    - 建材漲價。
    - **詐欺**：控管主要依賴民間專業者的證明。
- **抵減權移轉缺乏控管**（UPB，2023-03）：2020 年起抵減權幾乎可以無限次轉賣，適用所有建物抵減（含 Sismabonus），但沒有同步加強防詐。2021～2022 年政府連續修法限制轉賣次數，並要求價格合理性證明、對不實簽證的技師加刑責。【文件】[4]
- **錢流向有錢人與北部**（UPB，2023-03）：【文件】[4]
  - 傳統建物抵減高度累退。一半金額由約 10% 最富有、有房產、有高收入、有現金能先付款的人使用。
  - 超過 60% 的抵減金額由北部居民使用。
  - Superbonus 允許賣抵減權後，南部的比例一度上升，但 2022-04 起又從 37.9% 掉到 2023-01 的約 20%。
- **補助沒有照風險排序**：
  - 制度設計就是「不設排序、自願申請」。【文件】[3]
  - 北部多數地區的地震危險度低於中南部亞平寧山區。錢集中在北部，表示補助與地震風險錯開。【推論】（危險度分布未在本檔查證）
  - 這和土耳其「都更集中在高地價區」是同一種現象：用財務誘因、由屋主自己申請，結果跟著錢走，不跟著風險走。【推論】
- **耐震只占小份額**：PNRR 目標裡耐震面積約占 12%。Superbonus 主要被拿去做節能。【文件】[4]、【推論】
- **2025 年起分級和補助脫鉤**：2025～2027 年的抵減是固定比率，不再依「進步幾級」加碼。A+～G 分級失去了最主要的政策用途。【文件】[1]、【推論】
- **審計院（Corte dei conti）的評論**：這輪沒有讀到原文。【待確認】
- **詐欺金額**：媒體常引「上百億歐元不實抵減權」，這輪沒有讀到稅務局（Agenzia delle Entrate）原始數字。【待確認】

## 最新動態（2023～2026）

- **2023-02-17 起（DL 11/2023 第 2 條）**：一般禁止新案選擇「發票折抵」與「抵減權移轉」。【文件】[7]
  - 例外：已提出開工申報（CILA）或建照申請的案件。
  - 例外：2009 年阿布魯佐（Abruzzo）與 2016 年中部地震災區的重建，2024 年上限 4 億歐元。
  - 例外：1～3 震區的「城市更新計畫」原本也可，DL 212/2023 縮到只剩拆除重建。
- **DL 39/2024**：再刪除部分例外，加強事前與事後監測。UPB 對「加強監測」給正面評價。【文件】[5][7]
- **2025～2027**：抵減改為固定比率。2025～2026 年一般 36%、自住主屋 50%；2027 年一般 30%、自住主屋 36%。【文件】[1]

## 對臺北的可轉移性

- 可以借：
  - **A+～G 八級＋兩參數取較差**：一個經濟面（年平均損失）、一個安全面（生命安全指標），最後取較差的一個。屋主看到一個字母，專業者看得到兩個分數。【文件】[2]
  - **星號制度**：簡化法（推估）的等級加星號。這正好解決臺北 S2 的兩難：我們只有屋齡與構造的推估，沒有結構計算。結果可以標成「`C*`」，明講是推估。【推論】
  - **「進步幾級」的語言**：補強或重建的效果用「從 E 到 C」表達，比「耐震能力提升 30%」好懂。【推論】
  - **反面教材**：用稅賦抵減、自願申請、不排序，錢會跟著財力走。臺北的 S3 論述可以引用 UPB 的累退性數字。【推論】
- 不能直接借（為什麼）：
  - 傳統法要做結構分析（PGA_C）。黑客松沒有逐棟結構資料，算不出真正的 PAM 或 IS-V。【推論】
  - 簡化法的 V1～V6 是針對磚石造。臺北的主要存量是鋼筋混凝土公寓，要另外定義「脆弱度等級」。【推論】
  - 義大利的震區 1～4 是全國分區。臺北市在臺灣的分區中只有一級，區內差異要靠液化、地盤等因子補。【推論】
- 前提條件：
  - 臺北版「脆弱度等級」需要可公開取得的建物屬性：建成年（實價登錄、使照）、構造、樓層。R1 已發現 81% 的戶沒有開放的逐棟屋齡。【文件】`research/issue-06/PLAN.md` 第 3 節
  - 臺灣耐震規範的修訂年份與對應的設計要求，由 C2 提供，不在本檔查證。
- 對應解法方向：
  - **S2（地址查詢）**：最直接。把查詢結果包裝成「推估耐震標示 `C*`」，加上「怎麼變成確定等級」（老屋健檢、耐震初評）與「怎麼進步」（補強、重建）。
  - **S1（儀表板）**：「兩參數取較差」可以借成「因子分開顯示、總評取最差因子」的模式，避免加權總分把一個極端因子平均掉。
  - **S3（市場缺口）**：UPB 的累退性與北部集中數字，是「誘因跟著錢走」的國際佐證。

## 可以直接抄的設計細節

### 1. 臺北「推估耐震標示」（S2 用，仿簡化法）

- 等級：`A+*`、`A*`、`B*`、`C*`、`D*`、`E*`、`F*`、`G*`。**星號必帶**。
- 對照表：照附件 A 表 5 的格式做一張「脆弱度等級 × 場址等級」矩陣。
  - 列：脆弱度 V1～V6。臺北版可以用「建成年段 × 構造」定義。年段切點用臺灣耐震規範修訂年份（向 C2 要），例如「最早一版規範前」＝V6、「最新規範後」＝V1。【推論】
  - 欄：場址等級。臺北版可以用液化潛勢（低／中／高）取代義大利震區。【推論】
  - 格子：填等級字母。
- 規則：
  - 只能往差的方向調整（照義大利「偏離平均只能往更脆弱」）。例如「海砂屋列管」「地震黃單」直接降到最差一級。
  - 推估等級與正式評估等級並列時，以正式評估為準。
- 頁面顯示：
  - 大字母（如 **`D*`**），旁邊一句白話：「推估：與新建物相比，年平均地震損失約為 X 倍」或「推估：高關注」。
  - 下面一行小字：「* 表示依屋齡、構造、地質推估，非結構計算結果。」

### 2. 兩參數卡（S1 或 S2 進階頁）

- 左卡：**經濟面**（仿 PAM）：用「年平均預期損失」的概念，臺北版可以改成「損失潛勢分數」。
- 右卡：**安全面**（仿 IS-V）：用「生命安全」概念，臺北版可以改成「人命風險分數」（高齡、窄巷、救災可及性）。
- 總評：取兩卡中較差的等級。卡片上寫「總評取較差者，不平均」。

### 3. 「進步幾級」說明元件

- 顯示：「目前 `D*` → 補強後可能 `C*` → 重建後可能 `A*`」。
- 每一步附「怎麼做」（老屋健檢、補強補助、危老重建）與「誰能申請」。
- 義大利的經驗是：級數語言讓補強效果可比較，也方便把補助綁在「進步幾級」上。【文件】[3]

### 4. 正式分級的計算公式（若未來市府有逐棟結構資料，直接用）

- `λ_i = 1 / T_rC,i`，`T_rC = T_rD × (PGA_C / PGA_D)^(1/0.41)`
- CR：SLID 0%（λ=0.1）、SLO 7%、SLD 15%、SLV 50%、SLC 80%、SLR 100%（λ_SLR = λ_SLC）
- `PAM = Σ |Δλ| × (CR_i + CR_{i−1}) / 2 + λ_SLC × 100%`
- `IS-V = PGA_C(SLV) / PGA_D(SLV)`
- 級距：見本檔「機制細節」表 1、表 2。總評取較差者。
