# 都更試算機（`renewal-calculator-v2`）

針對原版「我家都更划不划算？」（`renewal-calculator/`）改版的新頁面，原始版本保留不更動。

## 核心設計目標

**讓使用者對都更感到有興趣、有點期待都更。**

1. **地址從 URL 參數帶入，必要參數另外填**：
   - 支援 `?addr=大安區信義路2段86巷40號`（自動解析行政區）或 `?t=63000030&q=信義路2段86巷40號`，亦支援選填 `&ping=31`。
   - 進入頁面即自動帶出該棟公開資料並以預設坪數算出結果。
   - 畫面頂部僅凸顯必填參數「**你家權狀幾坪？**」（附常用坪數快速按鈕），容積獎勵、共同負擔、土地持分算法等進階假設收合於展開區。
2. **先呈現「試算結果」，再呈現「生活代價」**：
   - **第 1 節（都更試算結果）**：聚焦換住全新電梯耐震大樓的升級亮點與未扣過渡期成本的「房屋身價增值」（只要更新後價值大於現況即以正向綠色呈現）。
   - **第 2 節（施工期間的生活代價）**：將施工等待期間（年數）、在外租屋月租、搬家安頓費與「都更資產增值」並列長條對比，並提供「實施者補貼拆遷安置費」勾選與最終淨收穫、里平均所得負擔力參考。
3. **極簡 Demo 畫面配置與華麗金幣＋鈔票慶祝特效**：
   - 進入頁面時預設僅展開頂部「**地址＋必填坪數**」卡片，「**1. 都更試算結果**」、「**2. 生活代價**」、「**3. 都更智慧搜尋**」、「**4. 怎麼算的**」四張卡片皆預設收合（`<details class="card toggle-card">`）。
   - 「**1. 都更試算結果**」收合時先賣關子（顯示 `✨ 點擊揭曉你家 31 坪老屋變新房後，身價躍升多少！` 與金色跳動按鈕 `🎁 點擊揭曉`）。
   - 點開「**1. 都更試算結果**」瞬間，觸發全螢幕**華麗金幣（3D 旋轉閃亮金幣）＋千元大鈔（飛舞鈔票）＋彩帶噴發雨**（底部禮炮噴射＋漫天金幣鈔票雨雙軌特效），同時卡片發光、試算金額從 0 快速跳動累加至目標增值金額！
4. **Google Search AI Overview 風格「都更智慧搜尋」**：
   - 採用類似 Google 搜尋＋AI 摘要（AI Overview）的完整問句搜尋體驗，而非傳統對話框。
   - 為配合 Demo，搜尋欄預設帶入「**我家是古蹟可以都更嗎?**」，按下「搜尋」後經 0.5 秒載入動畫，呈現「一句話正向結論＋3 種文資身分出路小卡（指定古蹟賣容積移轉變現／歷史建築併同都更享最高 1.5 倍獎勵／古蹟鄰地 50m 內過都審即可都更）＋一鍵套用高容積獎勵試算按鈕＋法規依據標籤」。
5. **移除與錢無關或潑冷水的資訊**：
   - 移除「需要幾戶同意」（100 格小人與法定同意門檻）。
   - 移除「換個新房價格算算看」翻轉圖與「5. 你可以走的路」（35 條替代方案決策樹）。
   - 共用 `../renewal-calculator/data/` 資料檔，不重複存放 34 MB 靜態資料。
