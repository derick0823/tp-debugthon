# 示範影片劇本：老屋耐震 6 個 MVP

- 長度目標：約 100 秒。16:9，1280×720，30 fps。
- 主要觀眾（TA）：住在臺北 30 年以上老公寓的住戶，40～70 歲，沒讀過都更條例，聽過「都更」但覺得很遠、很煩、會被騙。次要觀眾：里長、市府承辦、評審。
- 語氣：像鄰居在講，不像公文。每句配音 ≤ 25 字。字幕與配音同步，一句一行。
- 配音：edge-tts `zh-TW-HsiaoChenNeural`（女聲，親切）。備案 Windows 內建 Hanhan（離線）。
- 配樂：自製輕柔和弦 loop（video/assets/music.wav，無版權問題），音量 −18 dB，配音時再降 6 dB。
- 字幕特效：每句從下方淡入上移 12 px；關鍵字（金額、戶數、里名）用主色 #db6a41 放大 1.15 倍彈一下；段落切換用 theme 色塊擦過。
- 色票：design-kit/theme-puma.css。字體 Noto Sans TC。

## 錄影規格（給每位作者）

1. 檔案：`<你的資料夾>/demo/scenario.json`，格式見 `video/tools/record.py` 檔頭。viewport 固定 1280×720。
2. 長度：照上表的秒數，誤差 ±3 秒。開頭先 `wait` 1.5 秒讓頁面長出來，結尾 `wait` 1 秒。
3. 動作要「看得見」：滑桿用 `slider_sweep` 慢慢拉，不要瞬間跳；點東西前先 `hover` 0.4 秒；需要捲動用 `scroll_to`。
4. 在要配字幕的地方放 `{"do":"caption","text":"..."}`，文字照上表配音句切分（一句一個 caption）。
5. 錄：`uv run --with playwright python -X utf8 research/issue-06/mvp-variants/video/tools/record.py <name> <scenario.json>`，name 用資料夾名。產出在 `video/recordings/<name>.webm` 與 `.json`。
6. 驗：`.json` 裡 `errors` 要是 0；用無頭 Edge 開 webm 截一張圖或用 ffprobe 看長度。交件一行：name、秒數、errors。
7. 不改頁面程式；若選擇器不好選，加 id 可以，commit -- 自己路徑。
