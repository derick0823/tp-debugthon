# MVP 變體 F：屋頂願景（rooftop-vision）

- 作者：debug-66。發起：使用者 2026-10-23 早上的想法，由 MVP專案經理 轉派。
- 使用者原話：「臺北老房子屋頂都是鐵皮，從頂樓往下看很醜。做一個願景式的未來房屋設計，讓都更民眾也能參與設計建議，模擬給他們看都更後的樣子。」

## 怎麼開

伺服器用 MVP專案經理 開的 8778（根目錄 `research/issue-06`）：

```
http://127.0.0.1:8778/mvp-variants/rooftop-vision/
```

可用網址帶狀態，方便簡報與截圖：`#s=solar&a=lift,rain&p=20`。

- `s`：方案，可填 `green`、`solar`、`facade`。
- `a`：加上的元素，可填 `balcony`、`lift`、`garden`、`rain`。
- `p`：把手位置，0～100。

## 頁面有什麼

1. 第一屏是一個街廓的插圖（inline SVG，自己畫）。拖中間的把手：左邊是現在（鐵皮加蓋、水塔、天線、鐵窗、電線），右邊是都更後。
2. 三種方案可切換：綠屋頂、太陽能、統一色與立面。
3. 「我想加的」四個勾選：陽台綠化、無障礙電梯、社區菜園、雨水回收。勾了，插圖上就淡入對應的元素。把手會自動往左移，讓「都更後」露出來。
4. 三張方案卡，各有 3 個優缺點圖示與「我喜歡這個」按鈕。票數存在這台裝置的 localStorage，用長條顯示。
5. 手機寬度小於 560 px 時，插圖放大到中間三棟，屋頂才看得清楚。
6. 頂端任務列（`design-kit/quest.js`）：看前後、挑方案、加一個、投一票，每步 10 分。配色用 `design-kit/theme-puma.css`。網址帶的狀態不算分，只有使用者自己操作才算。

技術：純 HTML＋CSS＋原生 JS。字級與長條用 `../design-kit/kit.css`、`kit.js`。沒有套件、沒有追蹤碼。

## 證據等級

- 插圖是示意，不是任何真實建物【推論】。
- 優缺點是一般常識的整理【推論】。補助、承重、法規都還沒查【待確認】。
- 票數只在這台裝置。沒有上傳，也不是民調。
