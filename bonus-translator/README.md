## 為什麼

隊友說都更案容積頁的「ΔF1～F6 不是人看的」。使用者 10/22 夜加了要求：多圖、少字。本變體做兩件事：

1. **獎勵積木**：法定容積是底座，每一項獎勵是一塊不同顏色的積木，高度照面積比例，虛線是 1.5 倍上限。點一塊才看白話、檢核與法源。
2. **我的里**：給市民看的里況。上方圓環是「排進前 10% 的比例」，五格色塊是五件事的等級，點一格才看兩句說明。承辦人版仍是 `solutions/prototype/brief.html`，本頁連過去，不重做。

每段文字最多 2 句，細節收在 `<details>`。圖用 inline SVG，動畫用 CSS transition，沒有外部套件。

## 已知限制與待確認

1. **平台欄位 ↔ 法條的對應，舊制是【文件】，新制是【推論】**。新制欄位名（`SEISMIC_DESIGN` 等）是看英文名稱配到條號，沒有看到平台的欄位說明。目前內建的案都是舊制，新制還沒有實案驗證。
2. **ΔF4-3 的意思【待確認】**。法條沒有「4-3」編號。可能是「捐贈都更基金」或「協助市有建築物整建維護」。
3. **ΔF5-7 平台沒有欄位**。平台只回傳 F5_1～F5_6【實測】。108-01-01 以後用評定因素七的案，ΔF5-7 可能被併進別的欄。
4. **適用版本因案而異**。一案用哪一版評定標準，看報核日與是否選用新規定（評定標準 §3）。本頁的白話以 101／107／108 版的共同內容為主；各版比例不同的地方寫在 `condition`。
5. **北市新制加給項目的比例【待確認】**。附表原文 PDF 沒讀到，只讀了建築師公會講義。
6. **里況分頁的「都更審議案件」只列已載入的案**。E3 的全市案件表完成並經 debug-6f 審過後，改讀那張表。
7. 手機 375 px 用 iframe 量過不橫捲【實測】，沒有實機。
